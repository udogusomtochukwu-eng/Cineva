# Cineva

Cineva is a modern movie discovery app built for browsing trending titles, searching the TMDB catalog, filtering results, and saving favorites to a personal watchlist. It brings together discovery, recommendation, and lightweight personalization in one streamlined React experience.

## Tech Stack

- React
- Vite
- Tailwind CSS v4
- Framer Motion
- React Router
- TMDB API
- lucide-react

## Setup

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file in the project root and add your TMDB key:
   ```bash
   VITE_TMDB_API_KEY=your_api_key_here
   ```
4. Run the app locally:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
